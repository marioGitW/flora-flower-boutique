The choreography

  1. 0.0sPaper opens — cream and kraft sheets fan out from the tie point.
  2. 0.4sBack flowers rise out of the wrap, centre first.
  3. 0.8sFront flowers bloom in place, petals unfurling layer by layer.
  4. 1.1sEucalyptus and leaves grow outward from between the blooms.
  5. 1.6sGypsophila sparkles in to fill the gaps.
  6. 1.9sThe ribbon ties — loops spring out, tails swing and settle.
  7. 2.7sIdle — a slow breathing sway and a few falling petals.

Why it reads as modern

Real spring physics. Every pop and settle uses a damped-spring curve written into CSS linear(), so things overshoot and settle like objects rather than easing like slides. No GSAP.

Stagger from the centre. Flowers arrive in rings from the middle outward, the way a florist builds a bouquet.

Depth. On desktop the bouquet tilts toward the cursor and its layers separate in parallax. On every device, scrolling away tilts it back with the same CSS scroll timeline as the marquee band.

What it costs

One inline SVG of about — generated markup, zero image requests. The headline paints immediately and stays visible throughout — the letters only settle, they never fade in — so the name is your LCP element and the animation can't delay it.

In the Astro project the SVG renders at build time, so the bouquet is there with JavaScript off. The only script left is the pointer parallax, about 1 KB.

The flowers are Flora's actual mix from the Instagram photos: coral and deep rose, blush garden roses, white chrysanthemums, gypsophila and eucalyptus, in the cream-and-kraft wrap with satin ribbon the shop really uses.
